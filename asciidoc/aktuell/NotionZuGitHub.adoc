    - Alter

    -   Geschlecht
    - Alignment
    - Klasse oder Job(Background)
        - Darauf basierend:
            - Ability Score
                - Strength
                - Dexterity
                - Constitution
                - Intelligence
                - Wisdom
                - Charisma
            - Stats
                - Rüstungsklasse(AC)
                - HP
                - Geschwindigkeit(Speed in ft.)
                    - Laufen(walking)
                    - Fliegen(flying)
                    - Graben(burrowing)
                - Skills
                - Rettungswürfe (Saving Throws)
                - Actions
                - Senses
                - Spells
            - Sprachen
            - Glaube
    - Beschreibung
        - Stimme
        - Kleidung, Rüstung
        - Aussehen
        - Größe

== 5. Reihenfolge der Generation 

Auswahl ob zufälliges generieren oder gezieltes Auswählen bestimmter Attribute aus wählbare Attribute sind:

- Rasse
- Klasse
- Geschlecht
- Level
- Generationsmethode
- Rasse (zufällig oder gewählt)
- Klasse, Job (zufällig oder gewählt)
- Ability Scores (zufällig)
- Verteilung der Werte nach einer festgelegten Gewichtung, Abhängig von der vorher festgelegten Klasse
- LVL ( zufällig oder gewählt)

Aktionen hinzufügen anhand:

- Rasse
- Klasse, Job
- LvL
    
Beschreibung hinzufügen:

- Name
- Gesinnung (Alignment)
- Stimme
- Kleidung, Rüstung
- Aussehen
- Größe
- Verhalten (optional)
- Religion
- Plot Hook

==== Wenn der Stat Block, NPC fertig ist:

Exportieren:

    - Bild: JPEG, PNG, …
    - JSON Datei ( um in VTT zu impotieren)
    - .txt
    - Excel, LibreExcel
    - PDF

Speichern

    - interne Speicherung

Bearbeiten

    - alle Punkte können manuell bearbeitet werden
    - bearbeitete Punkte sollen andere betreffende Punkte ebenfalls ändern
    - Aktionen, Skills könne frei hinzugefügt und entfernt werden

Löschen

    - manuelles löschen von NPC´s
    - automatisches löschen von NPC´s ab einer bestimmten Anzahl ( nur nicht gespeicherte betreffend)

== 6. Berechnungen und Tabellen
- Disadvantage anzeigen
- Berechnung und Infos
    - HP
        
        HP = (LvL)d(Würfel durch Klasse bestimmt) + ( (CON Modifier) * LvL) 
        
    - AC
        
        AC = 10 + Rüstung + Schild + Boni 
        
    
    - Initiative
        
        Ini = Dex Modifier (+Bard of all Trade) (+Rasse)
        

    - Skills
        
        - Skills = Ability Modifier + Prof Bonus
